New Component Plan
For my new component, I plan to create a responsive cat information card using CSS Grid. Each card will include a cat photo, name, short description, favorite activity, and an icon.

The cards will be arranged in columns on larger screens and change to one column on smaller screens. This will make the information easier to read on phones and tablets.

I chose this component because my site already uses cat cards, but I can improve them by making the layout more consistent and reusable. The same card style could also be used for future pets or additional information.

Weekly Reflection
What did you create or organize this week that will be most useful in future websites?
The ComponentLibrary will be the most useful because it gives me a place to save reusable elements. I can keep my cards, buttons, forms, navigation bars, tables, and galleries there instead of starting from scratch every time.

I also organized my images and media into separate folders. This will make my projects easier to manage.

How did working with reusable components affect your design process?
Working with reusable components made me think more about consistency. I had to consider how the same design could work with different text and images. It also helped me keep the spacing, colors, fonts, and layouts more consistent throughout the site.

Responsive Design Reflection
When I resized my browser window, the gallery and cat cards were the elements that benefited most from media queries. On smaller screens, the cards stack vertically and the images become easier to view.

The navigation bar and form also benefit from responsive styling because their spacing needs to change on smaller screens.

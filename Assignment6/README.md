Project Overview
For Assignment 6, I created a responsive cat information card component using CSS Grid. Each card includes a cat photo, name, short description, favorite activity, and an icon.

The cards appear in multiple columns on larger screens and change to a single-column layout on smaller screens. This makes the content easy to read on desktop computers, tablets, and phones.

Purpose
The goal of this assignment was to improve the existing cat cards by making them more consistent, reusable, and responsive. The same card design can also be used in the future for other pets or new types of information.

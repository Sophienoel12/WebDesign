Assignment 4 - README Questions
Visual Appeal
I ended up using six icons: a cat face, paw print, sun, compass, cushion, and heart. The cat face and paw print match the overall theme of the site. The other icons connect to the cats’ personalities. For example, the sun represents Honey because she likes warm places, and the compass represents Maple because she likes exploring.

I used different shades of pink, white backgrounds, rounded corners, and simple borders throughout the site. I chose these because they make the website feel soft, friendly, and consistent without making it look too busy.

I used Bree Serif for my headings because it has a fun, playful look. I used Nunito Sans for the regular text because it is simple and easy to read.

Structure & Organization
My table organizes each cat’s personality and favorite activity. A table made sense because it lets visitors compare Honey, Maple, and Bennie quickly.

For my form, I used labels, spacing, borders, a fieldset, and a legend to keep everything organized. I also grouped similar questions together and used text boxes, a dropdown menu, radio buttons, and a checkbox.

Design Goals
The goal of my form is to give visitors a way to share information about themselves and their cats. This fits with my site because the whole website is focused on cats and their personalities.

The gallery helps visitors see Honey, Maple, and Bennie instead of only reading about them. It adds more personality to the site and makes the page more interesting to look at.

I used a mostly uniform pattern for the cat cards and gallery. The repeated image sizes, spacing, borders, and captions help everything look like it belongs together.

Checking In
Learning and applying design principles: I’m getting more comfortable using ideas like hierarchy, alignment, color, and pattern.

Using typography: I’m learning that fonts can change the mood of a website, but they still need to be easy to read.

Creating components: I feel more comfortable building navigation bars, cards, forms, buttons, tables, and galleries.

Exploring display: flex;: Flexbox has been helpful for arranging my cat cards and gallery. It also makes it easier to adjust the layout for smaller screens.

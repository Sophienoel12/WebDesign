# ComponentLibrary — Module 7 starter

This is a **new starter library**, not a replacement for your previously created class ComponentLibrary. Move or merge reusable components into your own existing library before submission if your instructor expects continuity.

- `index.html`: sandbox for editing component variants.
- `components.html`: reusable structures for site navigation, hero, card row, contact banner, and footer.
- `styles/styles.css`: rules grouped by component.
- `images/`: original SVG placeholders.

Copy both HTML structures and their CSS class rules when reusing a component in a different project. Do not link this stylesheet from the `Assignment7` website: the two are separate projects.
